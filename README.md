
# ParkSmart Frontend

ParkSmart is a parking management system frontend built with React and Vite.

## Features
- User interface for parking management
- Connects to the ParkSmart backend API
- Supports parking booking and payment QR display

## Technologies
- React
- Vite
- JavaScript
- CSS

## Run Locally
1. Install Node.js.
2. Open this folder in Command Prompt.
3. Run `npm install`.
4. Run `npm run dev`.

## Backend
The frontend communicates with the Spring Boot backend. Configure the backend API URL as required for your environment.
